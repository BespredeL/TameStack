🖥 Готовое настольное приложение для централизованного, безопасного и наглядного администрирования Linux-серверов по SSH в реальном времени.

TameStack устраняет необходимость держать десятки открытых терминалов и вручную исполнять сотни bash-команд. Приложение объединяет гибкость и мощь CLI-автоматизации с удобством, скоростью и безопасностью современного графического интерфейса на Go и Wails.

В отличие от традиционных веб-панелей, TameStack работает как **локальное настольное приложение**: на целевых серверах **не требуется** устанавливать фоновые демоны, агенты или открывать сторонние веб-порты — всё взаимодействие происходит исключительно через защищенный протокол **SSH**.

## ✨ Возможности

- 🖥️ **Мультисерверное управление:** мониторинг десятков VPS и выделенных серверов (семейства Debian/Ubuntu и RHEL/AlmaLinux/Rocky), глобальная телеметрия ресурсов (CPU, RAM, диски, сеть, Load Average, Uptime), фильтры доступности серверов (Все, В сети, Офлайн) и карточка целевого сервера со стеком и быстрыми действиями.
- 🔐 **Сейф учетных данных (Vault):** локальное шифрование секретов (SSH-ключи, пароли, sudo-токены, API-ключи AI) алгоритмом **AES-256-GCM** с деривацией ключа через **PBKDF2**; опциональная блокировка мастер-паролем.
- 🛡️ **Строгая безопасность SSH:** проверка Host Keys через `known_hosts` с защитой от MITM-атак, маскирование секретов в логах (`[REDACTED_SECRET]`).
- 🕵️ **Сканер безопасности файлов:** поиск недавно измененных и подозрительных файлов, эвристический анализатор web-shell/обфусцированного PHP/бэкдоров, контрольные снимки файлового дерева с дельта-сравнением, фоновое сканирование без нагрузки на сервер.
- 🔥 **Файрвол и Fail2ban:** управление UFW / Firewalld с защитой SSH-порта, детальная настройка джейлов Fail2ban (порты, фильтры, лог-файлы, findtime, bantime, ignoreip), динамический мониторинг активных джейлов и разблокировка IP-адресов.
- 🤖 **AI-ассистент и автономные агенты:** локальные модели (**Ollama**, **llama.cpp**, **vLLM**, **Unsloth**) и облачные провайдеры (**OpenAI**, **Anthropic Claude**, **Google Gemini**), адаптивный Model Router, стриминг и Tool Calling, долгосрочная память инфраструктуры на SQLite FTS5, обязательное подтверждение мутаций администратором (Human-in-the-Loop).
- 🌐 **Сайты, веб-серверы и PHP:** Nginx и Apache с изолированным просмотром логов, параллельные версии PHP (7.4–8.4+) с фильтрацией по статусу установки и совместимости с ОС (Установлено, Доступно, Не доступно), переключение FPM-сокета отдельного сайта без перезагрузки глобальных служб, управление пулами и расширениями, визуальный редактор `php.ini`, мастер создания сайтов с проверкой DNS.
- 🗄️ **Базы данных, Docker и сервисы:** MySQL, MariaDB, PostgreSQL и Redis (создание БД, пользователи, сжатые дампы и восстановление), полный жизненный цикл контейнеров, сетей, томов и Compose-стеков, контроллер служб systemd и инспектор сокетов.
- 📜 **SSL, Cron и бэкапы:** автоматический выпуск и продление Let's Encrypt / ACME через Certbot, визуальный планировщик Cron с разделением записей root и пользователей, локальные резервные копии сайтов и баз с политикой ротации.
- 📁 **Файловый менеджер:** SFTP-проводник с навигационными цепочками, встроенным редактором кода и безопасным выполнением привилегированных операций через `run_sudo`.
- 💻 **Интерактивный SSH-терминал:** вкладки, PTY-ресайз, полная совместимость с консольными утилитами (`htop`, `mc`, `nano`).
- 🌍 **Полная локализация:** двуязычный интерфейс (русский и английский) с моментальным переключением на лету.

## 🚀 Применение

- 🏢 **Веб-студии и фрилансеры:** ведение парк клиентских VPS с сайтами на Nginx/Apache и PHP из одного окна.
- 🛠️ **Системные администраторы:** рутина серверов (пакеты, службы, Cron, firewall, бэкапы) с аудитом и отменой опасных операций.
- 🤖 **DevOps с ИИ:** диагностика инцидентов и подготовка изменений через AI-ассистента с подтверждением каждой мутации.
- 🏭 **Инфраструктурные проекты:** инвентаризация серверов, аудит файлов, мониторинг доступности сайтов и SSL-сертификатов.

## 🧠 Как это работает

```mermaid
flowchart LR
    A[Оператор<br>Desktop UI React/Wails] --> B[TameStack<br>ядро на Go]
    B -- SSH + known_hosts --> C[Linux-сервер<br>root / sudo]
    B --> D[(Локальный SQLite<br>секреты AES-256-GCM)]
    E[AI-провайдер<br>Ollama / OpenAI / Claude / Gemini] -. Tool Calling .-> B
```

1. **Подключение:** сервер добавляется по SSH; при первом контакте отпечаток ключа проверяется и фиксируется в `known_hosts`.
2. **Аудит:** приложение читает конфигурацию ОС, службы и телеметрию только неизменяющими (read-only) командами.
3. **Task Engine:** длительные операции выполняются асинхронно, с этапами, отменой и потоковым логом в интерфейс.
4. **Мутации:** изменения конфигураций обязательно сопровождаются бэкапами файлов и двухэтапным подтверждением опасных действий.
5. **ИИ-помощник:** ассистент отвечает через строгие инструменты чтения и запрашивает разрешение на каждое изменяющее действие.

## 🛠 Технологический стек

### Backend
- **Go 1.23+**: высокая производительность, строгая типизация и низкое потребление памяти.
- **Wails v2 (v2.11+)**: нативный Desktop-рантайм без тяжеловесного Electron.
- **SQLite3 (modernc.org/sqlite)**: pure-Go встраиваемая база данных в WAL-режиме (компиляция без CGO).
- **golang.org/x/crypto/ssh**: протоколы SSH и SFTP, безопасность known_hosts.
- **AES-256-GCM + PBKDF2**: шифрование секретов на диске.

### Frontend
- **React 18 / TypeScript**: масштабируемая модульная архитектура интерфейса.
- **Vite**: сборщик модулей с мгновенным HMR.
- **Tailwind CSS**: эргономичная темная тема интерфейса.
- **Lucide Icons & Recharts**: системные иконки и векторные интерактивные графики телеметрии.

## 📦 Сборка и запуск

### Требования к окружению

- **Go 1.23+**
- **Node.js 18+** и **npm 9+**
- **Wails CLI v2.11+**:
  ```bash
  go install github.com/wailsapp/wails/v2/cmd/wails@latest
  ```

### Вариант 1: Режим разработки

```bash
# Клонировать репозиторий
git clone https://github.com/BespredeL/TameStack.git
cd TameStack

# Установить зависимости frontend
cd frontend && npm install && cd ..

# Запуск приложения с поддержкой live reload
wails dev
```

### Вариант 2: Сборка production-бинарников

```bash
# Для Windows (x64) — инсталлятор NSIS (создает установщик и .exe в build/bin/)
wails build -platform windows/amd64 -nsis

# Для Windows (x64) — стандартный исполняемый файл
wails build -platform windows/amd64

# Для Linux (x64)
wails build -platform linux/amd64

# Для macOS (Universal)
wails build -platform darwin/universal
```
